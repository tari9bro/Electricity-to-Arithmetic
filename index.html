What the switches do

Idealized inverter behavior.

INPUT = 0 · LOW

PMOS turns ON

The output is pulled up toward the supply voltage (VDD). The NMOS path to ground is off, so the modeled output is logic 1.

INPUT = 1 · HIGH

NMOS turns ON

The output is pulled down toward ground. The PMOS pull-up path is off, so the modeled output is logic 0.

Real transistor behavior depends on device physics, thresholds, loading, switching time and circuit layout.

From physics to computation

How electricity becomes arithmetic

A processor contains billions of transistors, but the high-level story can be understood by connecting a few ideas in order.

01 / VOLTAGE

Voltage represents states

Digital circuits treat voltage ranges as LOW and HIGH. These are interpreted as binary 0 and 1; a bit is an abstract state, not a literal object moving through a wire.

02 / TRANSISTORS

Switches control current

MOS transistors control conductive paths according to gate voltage. Paired devices build CMOS logic with useful switching behavior and low static power in stable states.

03 / LOGIC GATES

Rules become circuits

NOT, AND, OR and derived gates implement Boolean functions. Connecting gates creates adders, multiplexers, decoders, registers and more.

04 / BINARY

Numbers use place values

Binary digits represent powers of two. For example, 0101 means 0×8 + 1×4 + 0×2 + 1×1 = 5.

05 / ALU

The ALU performs operations

The arithmetic logic unit selects a datapath for the requested operation. Adders combine bit values and carry signals; subtraction can use two’s-complement arithmetic.

06 / REGISTERS

Results are stored

Clocked storage elements capture digital states. A register holds the encoded result so other parts of a processor can use it later.

07 / CONTROL

Control chooses what happens

Control logic coordinates which registers drive signals, which operation is selected and when results are captured.

08 / TIMING

Switching is not instant

Signals have propagation delay, and clocked circuits need timing margins. Clock figures in this lab are illustrative profiles, not measured performance claims.
